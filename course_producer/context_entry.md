# Context Entry Point - Course Producer Preset

**🎯 Точка входа для ИИ**

Этот файл описывает порядок чтения промптов и файлов для погружения в контекст пресета "Продюсер курсов".

## 📚 Порядок чтения для понимания контекста

### Шаг 1: Стратегия курса
**Начни с:** `prompt_course_strategy.md` (копируется в проект как `course_strategy_prompt.md`)

Этот промпт поможет:
- Разработать стратегию создания и запуска курса
- Определить целевую аудиторию
- Создать структуру и бизнес-модель курса
- Определить уникальное ценностное предложение
- Спланировать формат продажи и ценообразование

**Действие после чтения**: Создай обзор курса в `course_overview.md`

### Шаг 2: Структура курса
**Файл:** `prompt_course_structure.md` (копируется в проект как `course_structure_prompt.md`)

Используй для создания структуры:
- Детальная структура курса с модулями и уроками
- Логическая последовательность обучения
- Балансировка теории и практики
- Системы оценки и обратной связи

### Шаг 3: Производство контента
**Файл:** `prompt_content_producer.md` (копируется в проект как `content_producer_prompt.md`)

Промпт для создания обучающего контента:
- Сценарии уроков
- Практические задания
- Материалы для студентов
- Интерактивные элементы

### Шаг 4: Планирование запуска
**Файл:** `prompt_launch_planner.md` (копируется в проект как `launch_planner_prompt.md`)

Используй для планирования запуска:
- Предзапусковая подготовка (маркетинг, лист ожидания)
- Стратегия запуска (бонусы, скидки, вебинары)
- Техническая подготовка
- Пост-запусковая поддержка

## 🔄 Типичный workflow

1. **Стратегия**: Прочитай `course_strategy_prompt.md` → создай `course_overview.md`
2. **Структура**: Используй `course_structure_prompt.md` → создай `course_structure.md`
3. **Контент**: Используй `content_producer_prompt.md` для создания модулей
4. **Материалы**: Создавай материалы в папке `materials/`
5. **Запуск**: Используй `launch_planner_prompt.md` → создай `launch_plan.md`
6. **Маркетинг**: Подготовь материалы в `marketing_materials.md`

## 📝 Структура проекта

- `modules/` - файлы для каждого модуля и урока курса
- `materials/` - дополнительные материалы, задания, чеклисты
- `promo/` - промо-материалы для маркетинга
- `student_resources/` - ресурсы для студентов
- `course_overview.md` - обзор курса и его структура
- `course_structure.md` - детальная структура курса
- `launch_plan.md` - детальный план запуска курса
- `pricing_strategy.md` - стратегия ценообразования
- `marketing_materials.md` - материалы для продвижения курса
- `student_onboarding.md` - процесс онбординга студентов

## 🚀 Первый запуск проекта

После прочтения всех промптов:
1. Используй `course_strategy_prompt.md` для создания стратегии курса
2. Создай `course_overview.md` с концепцией и целями курса
3. Используй `course_structure_prompt.md` для детализации структуры
4. Создай `course_structure.md` с модулями и уроками
5. Используй `content_producer_prompt.md` для создания контента каждого модуля
6. Планируй запуск через `launch_planner_prompt.md`
7. Создай `launch_plan.md` и `marketing_materials.md`

---

**💡 Совет**: Начни с `course_strategy_prompt.md` - стратегия определит концепцию всего курса.
