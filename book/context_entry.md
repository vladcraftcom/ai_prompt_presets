# Context Entry Point - Book Writing Preset

**🎯 Точка входа для ИИ**

Этот файл описывает порядок чтения промптов и файлов для погружения в контекст пресета "Написание книги".

## 📚 Порядок чтения для понимания контекста

### Шаг 1: Планирование книги
**Начни с:** `prompt_book_planning.md` (копируется в проект как `book_planning_prompt.md`)

Этот промпт поможет:
- Структурировать идею книги
- Определить целевую аудиторию
- Планировать содержание
- Создать детальный план работы
- Определить стиль и тон написания

**Действие после чтения**: Создай детальный план в `book_structure.md`

### Шаг 2: Структурирование глав
**Файл:** `prompt_chapter_structure.md` (копируется в проект как `chapter_structure_prompt.md`)

Используй для детализации структуры глав:
- Планирование каждой главы
- Определение ключевых точек
- Создание переходов между главами
- Структурирование материала

### Шаг 3: Руководство по написанию
**Файл:** `prompt_writing_guide.md` (копируется в проект как `writing_guide_prompt.md`)

Промпт-гид для процесса написания:
- Правила стиля и структуры
- Техники написания
- Работа с диалогами и персонажами
- Использование примеров

### Шаг 4: Редактирование (для финальной проверки)
**Файл:** `prompt_editor.md` (копируется в проект как `editor_prompt.md`)

Используй на этапе редактирования:
- Проверка связности текста
- Проверка стиля и грамматики
- Предложения по улучшению
- Финальная полировка

## 🔄 Типичный workflow

1. **Планирование**: Прочитай `book_planning_prompt.md` → создай `book_structure.md`
2. **Структура глав**: Используй `chapter_structure_prompt.md` для детализации глав
3. **Написание**: Используй `writing_guide_prompt.md` как руководство при написании
4. **Отслеживание прогресса**: Регулярно обновляй `book_progress.md`
5. **Редактирование**: Используй `editor_prompt.md` для финальной проверки глав

## 📝 Структура проекта

- `chapters/` - файлы для каждой главы книги
- `research/` - исследовательские материалы и источники
- `drafts/` - черновики глав и разделов
- `notes/` - заметки, идеи, наблюдения
- `book_structure.md` - детальная структура книги
- `book_progress.md` - отслеживание прогресса написания
- `writing_log.md` - журнал процесса написания
- `editor_report.md` - отчет редактора (создается после редактирования)

## 🚀 Первый запуск проекта

После прочтения всех промптов:
1. Используй `book_planning_prompt.md` для создания общего плана книги
2. Создай `book_structure.md` с детальной структурой глав
3. Используй `chapter_structure_prompt.md` для детализации каждой главы
4. Начни писать главы в папке `chapters/`, следуя `writing_guide_prompt.md`
5. Регулярно сохраняй черновики в `drafts/` и обновляй `book_progress.md`

---

**💡 Совет**: Начни с `book_planning_prompt.md` - это основа для всей дальнейшей работы над книгой.
