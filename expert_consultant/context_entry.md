# Context Entry Point - Expert Consultant Preset

**🎯 Точка входа для ИИ**

Этот файл описывает порядок чтения промптов и файлов для погружения в контекст пресета "Эксперт-консультант".

## 📚 Порядок чтения для понимания контекста

### Шаг 1: Фреймворк консультирования
**Начни с:** `prompt_consultation_framework.md` (копируется в проект как `consultation_framework_prompt.md`)

Этот промпт поможет:
- Разработать структурированный подход к консультированию
- Определить методологию и процессы
- Создать протоколы консультаций
- Установить инструменты работы с информацией
- Определить области экспертизы

**Действие после чтения**: Создай профиль эксперта в `expertise_profile.md` и протокол в `consultation_protocol.md`

### Шаг 2: Управление знаниями
**Файл:** `prompt_knowledge_manager.md` (копируется в проект как `knowledge_manager_prompt.md`)

Используй для структурирования знаний:
- Организация базы знаний
- Создание связей между областями
- Структурирование информации
- Быстрый доступ к релевантным знаниям
- Обновление знаний на основе опыта

### Шаг 3: Анализ кейсов
**Файл:** `prompt_case_analyzer.md` (копируется в проект как `case_analyzer_prompt.md`)

Промпт для анализа клиентских кейсов:
- Диагностика проблем клиента
- Выявление корневых причин
- Поиск решений
- Структурирование опыта
- Обучение на основе кейсов

### Шаг 4: Генерация рекомендаций
**Файл:** `prompt_recommendation_engine.md` (копируется в проект как `recommendation_engine_prompt.md`)

Используй для создания рекомендаций:
- Генерация качественных рекомендаций
- Персонализация под клиента
- Обоснование решений
- Создание пошаговых планов
- Использование предыдущего опыта

## 🔄 Типичный workflow

1. **Фреймворк**: Прочитай `consultation_framework_prompt.md` → создай `expertise_profile.md` и `consultation_protocol.md`
2. **База знаний**: Используй `knowledge_manager_prompt.md` для организации знаний в `knowledge_base/`
3. **Карта знаний**: Создай `knowledge_map.md` с визуализацией структуры
4. **Работа с кейсами**: Используй `case_analyzer_prompt.md` для анализа в `case_studies/`
5. **Рекомендации**: Используй `recommendation_engine_prompt.md` для генерации рекомендаций
6. **Документирование**: Сохраняй записи консультаций в `consultations/`

## 📝 Структура проекта

- `consultations/` - записи проведенных консультаций
- `knowledge_base/` - структурированная база знаний и информации
- `case_studies/` - кейсы клиентов и их решения
- `templates/` - шаблоны для консультаций
- `expertise_profile.md` - профиль эксперта и области знаний
- `expertise_areas.md` - детализация областей экспертизы
- `consultation_protocol.md` - протокол проведения консультаций
- `knowledge_map.md` - карта знаний и взаимосвязей
- `client_cases.md` - база кейсов клиентов
- `recommendations_library.md` - библиотека типовых рекомендаций

## 🚀 Первый запуск проекта

После прочтения всех промптов:
1. Используй `consultation_framework_prompt.md` для разработки подхода
2. Создай `expertise_profile.md` с описанием экспертизы
3. Детализируй области в `expertise_areas.md`
4. Создай `consultation_protocol.md` с протоколом работы
5. Используй `knowledge_manager_prompt.md` для организации базы знаний
6. Создай структуру в `knowledge_base/` и карту в `knowledge_map.md`
7. Используй `case_analyzer_prompt.md` для работы с кейсами
8. Используй `recommendation_engine_prompt.md` для генерации рекомендаций

---

**💡 Совет**: Начни с `consultation_framework_prompt.md` - фреймворк определит методологию всей работы.
