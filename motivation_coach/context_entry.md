# Context Entry Point - Motivation Coach Preset

**🎯 Точка входа для ИИ**

Этот файл описывает порядок чтения промптов и файлов для погружения в контекст пресета "Мотивационный коуч".

## 📚 Порядок чтения для понимания контекста

### Шаг 1: Стратегия коучинга
**Начни с:** `prompt_coaching_strategy.md` (копируется в проект как `coaching_strategy_prompt.md`)

Этот промпт поможет:
- Разработать стратегию мотивационного коучинга
- Определить подходы и методологии
- Структурировать работу с клиентами
- Создать программы коучинга
- Определить философию коучинга

**Действие после чтения**: Создай философию коучинга в `coaching_philosophy.md`

### Шаг 2: Постановка целей
**Файл:** `prompt_goal_setter.md` (копируется в проект как `goal_setter_prompt.md`)

Используй для работы с целями клиентов:
- Постановка четких, достижимых целей (SMART)
- Разбиение больших целей на шаги
- Создание планов действий
- Преодоление препятствий
- Поддержание мотивации

### Шаг 3: Техники мотивации
**Файл:** `prompt_motivation_techniques.md` (копируется в проект как `motivation_techniques_prompt.md`)

Промпт для применения техник:
- Различные техники мотивации
- Адаптация под личность клиента
- Работа с препятствиями
- Поддержка и обратная связь
- Измерение эффективности

### Шаг 4: Отслеживание прогресса
**Файл:** `prompt_progress_tracker.md` (копируется в проект как `progress_tracker_prompt.md`)

Используй для мониторинга прогресса:
- Создание системы метрик
- Методы отслеживания
- Анализ результатов
- Корректировка планов
- Отчетность клиентам

## 🔄 Типичный workflow

1. **Стратегия**: Прочитай `coaching_strategy_prompt.md` → создай `coaching_philosophy.md`
2. **Работа с целями**: Используй `goal_setter_prompt.md` → создай `goal_framework.md`
3. **Техники**: Используй `motivation_techniques_prompt.md` для применения техник
4. **Программы**: Создавай программы в `programs/`
5. **Отслеживание**: Используй `progress_tracker_prompt.md` для мониторинга
6. **Отчеты**: Создавай отчеты в `progress_reports.md`

## 📝 Структура проекта

- `programs/` - программы коучинга для разных целей
- `exercises/` - упражнения и практики для клиентов
- `tracking/` - данные трекинга прогресса клиентов
- `resources/` - дополнительные ресурсы, материалы, инструменты
- `coaching_philosophy.md` - философия и методология коучинга
- `client_profiles.md` - профили клиентов
- `goal_framework.md` - рамка для постановки и достижения целей
- `motivation_toolkit.md` - набор техник и инструментов мотивации
- `progress_reports.md` - отчеты о прогрессе клиентов
- `session_notes.md` - записи сессий с клиентами

## 🚀 Первый запуск проекта

После прочтения всех промптов:
1. Используй `coaching_strategy_prompt.md` для создания стратегии
2. Создай `coaching_philosophy.md` с философией и подходом
3. Используй `goal_setter_prompt.md` для работы с целями клиентов
4. Создай `goal_framework.md` для структурирования работы с целями
5. Используй `motivation_techniques_prompt.md` для применения техник
6. Создавай программы в `programs/` и упражнения в `exercises/`
7. Используй `progress_tracker_prompt.md` для отслеживания прогресса
8. Веди записи сессий в `session_notes.md` и отчеты в `progress_reports.md`

---

**💡 Совет**: Начни с `coaching_strategy_prompt.md` - стратегия определит подход ко всей работе с клиентами.
