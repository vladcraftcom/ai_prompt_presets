# Context Entry Point - Coursework Preset

**🎯 Точка входа для ИИ**

Этот файл описывает порядок чтения промптов и файлов для погружения в контекст пресета "Курсовая работа".

## 📚 Порядок чтения для понимания контекста

### Шаг 1: Планирование исследования
**Начни с:** `prompt_research_planner.md` (копируется в проект как `research_planner_prompt.md`)

Этот промпт поможет:
- Планировать научное исследование
- Определить методологию
- Найти и структурировать источники
- Сформулировать гипотезу и задачи
- Создать временной план

**Действие после чтения**: Создай план исследования в `research_plan.md` и сформулируй тезис в `thesis_statement.md`

### Шаг 2: Построение структуры
**Файл:** `prompt_structure_builder.md` (копируется в проект как `structure_builder_prompt.md`)

Используй для создания структуры:
- Детальная структура курсовой работы
- Разделы и подразделы
- Логика изложения материала
- Обязательные элементы (введение, заключение, библиография)

### Шаг 3: Написание работы
**Файл:** `prompt_writer.md` (копируется в проект как `writer_prompt.md`)

Промпт для написания разделов:
- Научный стиль письма
- Структурирование мыслей
- Аргументация и доказательства
- Правильное использование терминологии

### Шаг 4: Оформление цитат и ссылок
**Файл:** `prompt_citation_helper.md` (копируется в проект как `citation_helper_prompt.md`)

Используй для правильного оформления:
- Цитаты и ссылки согласно стандартам (APA, MLA, Chicago, ГОСТ)
- Библиографический список
- Проверка валидности источников

## 🔄 Типичный workflow

1. **Исследование**: Прочитай `research_planner_prompt.md` → создай `research_plan.md`
2. **Тезис**: Сформулируй основную гипотезу в `thesis_statement.md`
3. **Структура**: Используй `structure_builder_prompt.md` → создай `coursework_structure.md`
4. **Сбор материалов**: Собирай источники в `research/` и `references/`
5. **Написание**: Используй `writer_prompt.md` для написания разделов в `sections/`
6. **Оформление**: Используй `citation_helper_prompt.md` для оформления ссылок
7. **Ведение лога**: Записывай прогресс в `research_log.md`

## 📝 Структура проекта

- `sections/` - файлы для каждого раздела курсовой работы
- `research/` - материалы, статьи, данные для исследования
- `references/` - библиографические записи
- `appendix/` - приложения, таблицы, графики
- `research_plan.md` - план исследования и методология
- `coursework_structure.md` - детальная структура работы
- `thesis_statement.md` - основная гипотеза/тезис работы
- `references_list.md` - список использованных источников
- `research_log.md` - журнал исследований
- `draft_notes.md` - заметки и черновики

## 🚀 Первый запуск проекта

После прочтения всех промптов:
1. Используй `research_planner_prompt.md` для планирования исследования
2. Создай `research_plan.md` с методологией и планом
3. Сформулируй тезис в `thesis_statement.md`
4. Используй `structure_builder_prompt.md` для построения структуры
5. Создай `coursework_structure.md` с детальной структурой
6. Собирай материалы в `research/` и библиографию в `references/`
7. Используй `writer_prompt.md` для написания разделов
8. Используй `citation_helper_prompt.md` для оформления ссылок
9. Веди журнал в `research_log.md`

---

**💡 Совет**: Начни с `research_planner_prompt.md` - план исследования определит направление всей работы.
