# Context Entry Point - Content Plan Preset

**🎯 Точка входа для ИИ**

Этот файл описывает порядок чтения промптов и файлов для погружения в контекст пресета "План контента".

## 📚 Порядок чтения для понимания контекста

### Шаг 1: Стратегия контента
**Начни с:** `prompt_content_strategy.md` (копируется в проект как `content_strategy_prompt.md`)

Этот промпт поможет:
- Создать эффективную стратегию контента
- Определить целевую аудиторию
- Выбрать форматы контента
- Планировать долгосрочный контент-план
- Определить цели и метрики

**Действие после чтения**: Создай детальную стратегию в `content_strategy.md`

### Шаг 2: Календарь публикаций
**Файл:** `prompt_content_calendar.md` (копируется в проект как `content_calendar_prompt.md`)

Используй для планирования календаря:
- Структурированный календарь публикаций
- Учет событий и сезонности
- Балансировка различных типов контента
- Планирование ресурсов

### Шаг 3: Создание контента
**Файл:** `prompt_content_creator.md` (копируется в проект как `content_creator_prompt.md`)

Промпт для создания контента:
- Создание качественного, вовлекающего контента
- Адаптация под специфику платформы
- Использование сторителлинга
- Оптимизация под алгоритмы

### Шаг 4: Оптимизация контента
**Файл:** `prompt_content_optimizer.md` (копируется в проект как `content_optimizer_prompt.md`)

Используй для оптимизации готового контента:
- Анализ на соответствие лучшим практикам
- SEO и алгоритмическая оптимизация
- Улучшение читаемости и вовлеченности
- Учет актуальных трендов

## 🔄 Типичный workflow

1. **Стратегия**: Прочитай `content_strategy_prompt.md` → создай `content_strategy.md`
2. **Календарь**: Используй `content_calendar_prompt.md` → создай `content_calendar.md`
3. **Идеи**: Собирай идеи в `content_ideas.md`
4. **Создание**: Используй `content_creator_prompt.md` для создания контента
5. **Оптимизация**: Используй `content_optimizer_prompt.md` перед публикацией
6. **Аналитика**: Отслеживай результаты в `performance_tracker.md`

## 📝 Структура проекта

- `content_calendar/` - календарь публикаций и расписание
- `assets/` - визуальные материалы, изображения, видео
- `templates/` - шаблоны для различных типов контента
- `analytics/` - аналитические данные и отчеты
- `content_strategy.md` - детальная стратегия контента
- `content_calendar.md` - календарь публикаций
- `content_ideas.md` - коллекция идей для контента
- `performance_tracker.md` - отслеживание метрик и аналитики
- `hashtag_research.md` - исследование и хранение релевантных хештегов

## 🚀 Первый запуск проекта

После прочтения всех промптов:
1. Используй `content_strategy_prompt.md` для создания стратегии
2. Создай `content_strategy.md` с детальной стратегией контента
3. Используй `content_calendar_prompt.md` для планирования календаря
4. Создай `content_calendar.md` с расписанием публикаций
5. Собирай идеи в `content_ideas.md` по мере появления
6. Используй `content_creator_prompt.md` для создания контента
7. Оптимизируй контент через `content_optimizer_prompt.md`
8. Отслеживай результаты в `performance_tracker.md`

---

**💡 Совет**: Начни с `content_strategy_prompt.md` - стратегия определит направление всего контент-плана.
